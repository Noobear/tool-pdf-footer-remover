# PDF 하단 텍스트 제거 도구

PDF 파일의 각 페이지 하단에 있는 **페이지 번호**와 **저작권 문구(코드 포함)**를 완전히 삭제하는 스크립트입니다.

## 폴더 구조

```
.
├── raw/              # 원본 PDF 파일을 여기에 넣으세요
├── output/           # 처리된 PDF가 여기에 저장됩니다 (자동 생성)
└── remove_footer.py  # 실행 스크립트
```

## 요구사항

- Python 3.7 이상
- PyMuPDF 라이브러리

## 설치

```bash
pip install pymupdf
```

## 사용법

1. `raw/` 폴더에 처리할 PDF 파일을 넣습니다.
2. 스크립트를 실행합니다:

```bash
python remove_footer.py
```

3. `output/` 폴더에서 처리된 파일을 확인합니다.

## 제거 대상

- 각 페이지 하단 중앙의 **페이지 번호**
- 각 페이지 최하단의 **저작권 문구**
  - 예: `이 자료는 저작권의 보호를 받는 합법 저작물로 무단 배포 및 재판매할 수 없습니다. (SV-XXXXX)`

## 주의사항

- 원본 파일은 변경되지 않습니다. 처리 결과는 항상 `output/` 폴더에 저장됩니다.
- 저작권 문구가 다른 언어이거나 다른 키워드로 시작하는 경우, `remove_footer.py` 내의 `COPYRIGHT_TEXT` 변수를 수정하세요.
